# Spotify Capsule

Generate a shareable image of your top 5 Spotify artists and songs from the last 4 weeks.

## Tech Stack

- [Next.js](https://nextjs.org/) (App Router)
- [Tailwind CSS](https://tailwindcss.com/)
- [Spotify Web API](https://developer.spotify.com/documentation/web-api)
- [html-to-image](https://github.com/bubkoo/html-to-image)

## Notes

- Spotify's `short_term` time range covers approximately the last 4 weeks
- Top artists data may take time to populate for new Spotify accounts
